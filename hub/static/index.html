Your tamale sessions, from anywhere.

tamale-hub puts tamale's web UI on your phone or any browser, wherever tamale runs: your laptop or a dozen throwaway servers. No port forwarding, no VPN. Each tamale connects out to the hub; your browser holds the key that lets you in.

  1. Make a token pair below. It has two halves: an agent token for the machines that run tamale, and a view link for your browsers.
  2. On each machine, set the agent token and run /web remote in tamale. The agent token alone can't read or drive anything, so it's fine on a VPS.
  3. On your phone, scan the view link. Your sessions show up here; tap one to drive it.

      How much to trust this hub
      
    
      Sessions pass through this server unencrypted beyond TLS, so whoever runs it, or anyone who
      breaks into it, could read them and send commands to your machines. It's a beta. For
      anything sensitive, run your own hub (it's one small binary behind Caddy), and
      keep tamale's permission mode on ask for remote work.
      
    
      Unused pairs made here are deleted after 7 days if they never connect, and after 90 days
      without use.
